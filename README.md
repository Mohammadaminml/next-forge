# 🚀 Next Forge CLI

![npm version](https://img.shields.io/npm/v/next-forge-cli?color=blue)
![license](https://img.shields.io/github/license/YOUR-GITHUB-USERNAME/next-forge)
![TypeScript](https://img.shields.io/badge/TypeScript-Ready-blue)

A powerful and blazing-fast Command Line Interface (CLI) to scaffold Next.js and React components. It automatically generates the component file, an `index.ts` for clean exports, and optional test files (Jest/React Testing Library) — all pre-configured with **TypeScript** and **Tailwind CSS**.

## ✨ Features

- ⚡️ Instantly generate React/Next.js components.
- 📘 Built-in **TypeScript** interfaces.
- 🎨 Pre-styled with **Tailwind CSS**.
- 🧪 Optional flag (`-t` or `--test`) to generate Jest/Testing Library test files.
- 📦 Clean export pattern (`index.ts` generation).

## 📦 Installation

You can install the package globally using npm:

```bash
npm install -g next-forge-cli
